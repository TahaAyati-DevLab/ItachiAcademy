<h2>🚀 About</h2>

<p>
  Itachi Academy is a backend project focused on practical
  <strong>Node.js development</strong>, RESTful API design,
  authentication, database integration, and clean project architecture.
</p>

<h2>🛠️ Tech Stack</h2>

<ul>
  <li>Node.js</li>
  <li>Express.js</li>
  <li>MongoDB</li>
  <li>Mongoose</li>
  <li>JWT</li>
  <li>REST API</li>
</ul>

<h2>⚡ Installation</h2>

<pre><code>git clone https://github.com/TahaAyati-DevLab/ItachiAcademy.git
cd ItachiAcademy
npm install</code></pre>

<p>Create a <code>.env</code> file and add the required environment variables.</p>

<pre><code>nodemon</code></pre>
<pre><code>npm run dev</code></pre>
